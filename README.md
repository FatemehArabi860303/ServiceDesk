
# ServiceDesk – ASP.NET Core / .NET 8 Support Management System

ServiceDesk is a portfolio project developed by Fatemeh Arabi,
a .NET software developer specializing in backend and enterprise applications.

The application demonstrates:

- ASP.NET Core Web API
- C# / .NET 8
- Entity Framework Core
- SQL Server
- JWT authentication and authorization
- RabbitMQ
- Outbox Pattern
- Event-driven architecture
- Background workers
- xUnit automated testing
